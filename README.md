Добро пожаловать в Jarvis — персональный ассистент, вдохновлённый Jarvis из "Железного человека". Это цифровой дворецкий для вашего ПК, который учится вашим привычкам, берёт на себя рутину и дарит свободу для творчества.

Создан на C# и WPF — для идеальной скорости, красоты и бесшовного опыта на Windows.

🚀 Что умеет Jarvis?
Функционал	Описание
🎤 Голос в команду	Поиск в интернете, заметки, действия — просто скажите! (System.Speech / Azure Cognitive Services)
📅 Умный планировщик	Контекстные напоминания: "Напомни, когда приду домой" — привязка к локации и времени
🔌 Открытая экосистема	Модульная архитектура: добавляйте плагины и команды за минуты
⚡ Супер-гибкость	DI (Dependency Injection) + MVVM для чистого, тестируемого кода
🛠️ Под капотом
Язык: C# (.NET)

UI: WPF — современные интерфейсы с анимациями и Material Design

Речь: System.Speech

Архитектура: MVVM + DI — легко расширять и поддерживать

✨ Почему Jarvis?
Эффективность: Автоматизирует 80% рутины.

Персонализация: Учится на ваших привычках.
